# 风格与讲述规范

## 取舍原则

学术准确性 > 内容完整与逻辑 > 有效信息密度 > 排版质量 > 预设页数。新任务明确的要求优先。学术组会通常需要比短报告更多的解释与细节，但不应为凑时长添加术语、重复页面或无关证明。

参考模板由用户另行提供。本公开版没有原始PPT、教学截图或学校标识，不能宣称可以逐像素复现某个私有模板。未提供参考时，可采用下列可调整的视觉基线，不假造机构品牌或校徽。

## 一页的内容组织

方法页应让听众理解：它在做什么、为什么值得做、主要限制是什么。可采用“一句引入＋机制图或关键公式＋少量解释＋收益/代价”；这是可选构成，不要求每页硬塞完整栏目。

优缺点要解释取舍。例如“把在线计算转移到离线训练，部署更快，但引入拟合误差与分布偏移”，比孤立写“效果好、效率高、缺乏保证”更有用。必要条件可以放短注或备注，但不能删去影响结论真假的前提。

分类只有在帮助后续理解时才值得展开。每个类别配一句机制或连接方式的说明，不只列名词。已经讲过的基础可以压缩成一张地图，新出现且承担关键逻辑的内容应适当展开。

## 建立方法联系

### 简短承接

用一句话说明前一种方法的瓶颈及后一种方法试图处理的部分。如果两种方法只是面向不同需求，应表述为不同取舍，而非先后升级。

### 视觉回顾

确有比较价值时，将前页公式或架构放回当前页，标出替换、增加或保留的项。例如比较两种优化方法时，保留相同目标，突出更新规则不同；比较模型连接方式时，保留共同控制流程，标出学习模块插入点。

可先展示干净底稿，再在下一页加入局部对照或标注。此类重复页服务逐步解释，不是新增一组知识。只截比较所需区域，保证符号、上下文与清晰度；避免随意堆叠截图或遮住正在解释的公式、页码和标题。

## 图片与数学

优先使用真实论文架构图解释信息流，并配少量中文标签。原图不适合当前问题时，不为装饰而强行使用。不要将原图中的文字变成投影时无法辨认的微小细节。

自写和改写公式使用可编辑原生数学对象；引用原文公式可以用清晰截取，必要时重排。截图不是准确性的豁免：仍需核对上下文、奖励与代价约定、最大化与最小化、梯度方向、条件期望和符号含义。

图、公式与结论的来源应在本次汇报中可追溯。使用者需自行提供可使用的资料；不能将私有参考文件或第三方素材默认重新公开。

## 可调整的视觉基线

若用户提供模板，以实际模板为准；否则可用16:9白底和以下层级：

| 元素 | 建议基线 |
|---|---|
| 页面主题 | 深绿粗体，简短直接；不使用口号替代学术主题 |
| 灰色引入 | 一句定义、动机或衔接，避免长摘要 |
| 模块标题 | 绿色或蓝色，层级高于正文 |
| 正文 | 主要黑色，短句及必要项目符号；不将整页文字全部染绿 |
| 优势与限制 | 正向强调可用绿，限制/代价可用橙；正文保持中性颜色 |
| 关系强调 | 少量下划线、箭头或短红注；同一强调符号的含义保持一致 |
| 分块 | 同类模块顶边、宽度、内边距对齐；浅绿与白底可交替，边框轻量 |
| 页眉页脚 | 保持清楚的章节与页码；只使用用户提供或允许使用的品牌标识 |

可选配色：深绿 `#006C39`、橙色 `#A13F0B`、蓝色 `#336699`、灰色 `#606060`、浅绿 `#EAF4EE`、细边框 `#C7D8CE` 或 `#DADADA`。

字体、字号及密度先服从用户模板和投影可读性，不把某一组具体字号当作所有画布的硬规则。空间不足时先重组表达或拆分真正不同的问题，不全局缩小正文。

## 常用版式

- 概念配例图：一侧解释定义，另一侧用同一个例子展示状态、动作或变量关系。
- 两到三种方法并排：采用相同维度比较机制、公式与取舍，避免各块讨论完全不同的问题。
- 推导流程：每个箭头对应一个有说明的近似或变换步骤，结果问题单独展示。
- 机制图配模块：图解释整体流程，模块说明训练/部署、实现或代价。
- 架构总览：真实结构图配一句连接方式说明，不自动把分类当作性能排名。
- 收束页：概括核心认识、仍未解决的限制及少量未来方向，不在结尾新增庞杂分类。

## 完成判断

听众应能说出核心方法的作用和主要取舍；有联系处应看得出“改了哪里”。图像与公式清楚，记号一致，分块支持概念对照，引用可追溯。最后检查对齐、字号层级、页码与图片比例。不要用装饰、放大标题或增加低密度页面掩盖内容缺口。
